# 已知边界与未完成项

这份清单优先写“不能宣称什么”。任何对外材料都不得越过以下边界。

## 1. 只有 Prompt 类策略，且没有真实模型证据

- **Prompt 类演化已实现**：`MockProposer`（预置补丁）与 `ReflectiveProposer`（失败轨迹 → 严格 JSON → 新指令），走完整的 register → run → validate → accept/reject 路径。
- **Memory / Tool / Skill 三类仍只有契约层**（schema + `TargetKind`），没有策略实现。
- 反思提议器只在**本地 mock LLM** 上验证过解析、重试、拒绝空改动；没有用真实模型跑过一轮闭环。
- `examples/evolve_demo.py` 的“初始 3/6 → bad 2/6 → good 5/6”是 MockRunner 的预置规则，**不是模型能力**。

## 2. 在线执行器存在，但未经真实端点验证

- `OfflineExecutor` 仍不含任何发送能力；`OnlineExecutor` 只有显式传入 runner 才会调用模型。
- `OpenAICompatibleRunner` 用本地 `http.server` 假端点验证了 429/500/超时/usage/并发/续跑，**没有对真实供应商端点做压测或长跑**。
- 真实 API 实验（R1/R2/R3）由仓库外的研究脚本完成，逐题账本未随包分发。
- 因此“已用真实模型完成在线自进化闭环并取得增益”不成立；能说的是“闭环代码路径已用 mock 端点端到端验证”。

## 3. 统计效力有限

- R1/R2 各 30 题、单种子、单次划分。R1 的 McNemar p=0.125，R2 的 p=0.5000。
- **不得写“统计显著”**，也不得写“已证明回归保护因果有效”。回归保护只在构造用例与 R2 的事后回放中体现为拦截行为，不是因果实验。
- 配对 bootstrap 只包含抽样不确定性，不含服务模型漂移与重复推理随机性。

## 4. R2 是负面结果

- 人工改进候选在新独立 30 题上 EM 倒退 6.67pp、回归 2 题。项目保留该结果，没有回选、没有据测试集改写候选。
- 门禁回放把 R2 在 `screen` 与 `release` 都拦下，这是**事后一致性的演示**，不是“门禁提前阻止了发布”的因果证据（当时并没有运行本门禁）。

## 5. 成本口径不统一

- R1 的成本比来自测试阶段 API 费用估算；R2 没有拆分单题费用，用**每题平均延迟**代理。两者不可直接比较，`evidence/historical_r2.json` 的 `cost.kind` 已标注。
- 费用均为按公开价目与返回用量估算，实际账单可能受缓存与免费额度影响。

## 6. 校园应用是确定性演示

- 10 份制度、36 道题全部为合成数据；`run-demo` 的 11/12 → 12/12 由预置规则解释器产生，`api_calls=0`。
- **没有真实高校授权、没有学生试用、没有公网部署、没有真实用户。**
- 三组问题（提议/验证/留出）是同类意图的措辞变体，语义独立性有限，不证明真实校园泛化。
- 真实模型候选质量、真实制度接入、学生试用均为“未验证”。

## 7. 公开与上游协作状态

- 本仓库是提交时冻结的 v1.0.0 快照；公开托管地址、Issue 跟踪与 PR 流程以实际发布为准。
- **没有已提交或已合并的上游 PR**；对 GEPA 的适配属于计划，不冒充已发生。
- 没有公开用户、下载量或第三方采用的可引用数据。

## 8. 已移除的合成结果

- 早期材料中的大样本预测成绩（题量与分数均为脚本预设，不是模型实测）**已从全部文件删除**，本仓库不再保留任何具体数字。
- “多次运行验证稳定性/方差”的分数同样是人工设定情景，一并删除。
- `runs/round3g`、`runs/round3h` 只保留聚合摘要；HotpotQA 原文、原始回答与逐请求账本不再分发。

## 9. 工程边界

- SQLite 状态适合单机；并发写入依赖 `BEGIN IMMEDIATE` 与文件锁，未做多进程写入压测。
- 凭证链不防“整链重建”，也没有外部锚定（签名/时间戳/公开日志）。
- 未做大规模性能测试；主套件约 3.5–4 分钟（234 项），主要花在 SQLite 提交（WAL +
  `synchronous=FULL`）与历史基准用例上。`examples/bench_write.py` 只压单进程 1000 条输出。
- 统计口径是流程约束，不是效果证据：MDE 给出“这个样本最多能说明什么”，但不能把
  “未检出”写成“无效应”；精确 McNemar 不做多重比较校正，族错误率只在选择偏差摘要里提示。
- 演化级续跑从 v1.2 起支持**轮次内**恢复（propose / run / validate / decide 四个阶段 + 5 个持久化
  边界），但只覆盖单机进程中断；磁盘损坏或状态库被外部改写不在承诺范围内。
- 未覆盖 Python 3.13；CI 固定 3.12。

## 10. 复现承诺的范围

- **可以一键复现**：`pytest tests/`、`scripts/demo_submission.py`、`examples/gate_replay.py`、`examples/evolve_demo.py`、校园示例及其测试。
- **不能一键复现**：重新花钱跑 R1/R2/R3，或用真实模型跑一轮闭环。需要自备 API Key、语料与预算，且逐题账本不在包内。
